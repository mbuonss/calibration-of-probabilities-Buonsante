## Project Description
This repository contains the experimental project dedicated to the **Calibration of Probabilities** (Assignment 2). The primary goal is to evaluate and improve the reliability of probabilistic estimates generated by classification models using post-processing calibration techniques.

All machine learning models and calibration algorithms have been implemented entirely **from scratch** using `numpy` for mathematical operations and `matplotlib` for generating visualizations.

### Implemented Algorithms
* **Classifiers:** Logistic Regression and Random Forest (built on top of custom Decision Trees).
* **Calibration Methods:** Platt Scaling and Isotonic Regression (implemented via the Pool Adjacent Violators algorithm).
* **Metrics & Visualizations:** Accuracy, Log-Loss, Brier Score, and Reliability Diagrams.
